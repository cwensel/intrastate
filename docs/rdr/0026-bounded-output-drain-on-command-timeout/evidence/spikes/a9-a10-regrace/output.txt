### RDR 0026 A10 spike: pollability probe ###
platform: darwin/arm64  go: go1.26.6
probe window: 10ms   parked-read observation: 300ms

--- A10(a): the probe DETECTS a non-pollable file ---
Claim: SetReadDeadline returns os.ErrNoDeadline on a file the runtime
poller never registered, so the caller can tell and fall back.

shape 1: regular file (os.Open of a temp file)
  SetReadDeadline(arm):   "file type does not support deadline" [errors.Is(err, os.ErrNoDeadline)=true, type=*errors.errorString]
  SetReadDeadline(clear): "file type does not support deadline" [errors.Is(err, os.ErrNoDeadline)=true, type=*errors.errorString]
  detected as non-pollable: true
  read after failed probe: n=21 err=<nil> content="regular file contents"

shape 2: os.NewFile over syscall.Dup of an os.Pipe read end
  (a genuine pipe fd, but never registered with the runtime poller)
  SetReadDeadline(arm):   "file type does not support deadline" [errors.Is(err, os.ErrNoDeadline)=true, type=*errors.errorString]
  SetReadDeadline(clear): "file type does not support deadline" [errors.Is(err, os.ErrNoDeadline)=true, type=*errors.errorString]
  detected as non-pollable: true
  read through the dup after failed probe: n=15 err=<nil> content="through-the-dup"

contrast: ordinary os.Pipe read end (expected pollable)
  SetReadDeadline(arm):   <nil>
  SetReadDeadline(clear): <nil>
  detected as non-pollable: false

  os.ErrNoDeadline as declared by the stdlib: "file type does not support deadline"

--- A10(b): the probe is a NO-OP on an ordinary pollable pipe ---
Claim: after probe+clear, a blocking Read on an EMPTY pipe with a live
writer still parks INDEFINITELY (no deadline error), then wakes on the
write with the right bytes. A leaked 10ms deadline would fire at 10ms,
30x sooner than the 300ms observation window.

WITH probe+clear, n=12
  still parked at 300ms (no deadline fired): 12/12
  woke on the write:                      12/12
  woke with the CORRECT bytes:            12/12
  trials with any error:                  0/12
  worst wake latency after the write:     68µs

WITHOUT probe (baseline), n=12
  still parked at 300ms (no deadline fired): 12/12
  woke on the write:                      12/12
  woke with the CORRECT bytes:            12/12
  trials with any error:                  0/12
  worst wake latency after the write:     38µs

## 6. D7(ii) provenance-scope note (home JD-17 "Open at (ii)", owner 0002)

**Home text.** §D7(ii) (home:325-327): "Readers and writers both declare `keys`; the loader refuses a key served by zero or two readers, a written or cleared key not in exactly one writer, and a writer key that is not owned." JD-17 entry (home:571-576): "**Open at (ii)** (critique N-4): 'a key served by zero … readers' refused at load cannot apply to `recognized` (kernel-supplied) or `--tag` keys (§JD-9) — the binding validation needs a provenance scope; owner 0002 at its re-entry, with 0004's semantics."

**0002 settlement** — fenced, `0002:675-707`:

> this RDR owns the layout and the **binding validations**, which are provenance-scoped:
> - every key in a `keys` list MUST be a declared tag (`unknown tag`), and MUST NOT be `recognized` — the kernel supplies that key and no accessor reads or writes it (RDR 0008);
> - every **owned** tag MUST be served by exactly one reader; an **observed** tag MAY be served by at most one reader, and zero is legal because an observed key may arrive from the caller (JDR 0001 §JD-9) — refusing it would make every `--tag`-supplied key unauthorable. […] the owned arm admits no write-only tag […]
> - every key named by any rule's write block or clear list, and every key assigned in `[initial]`, MUST be served by exactly one writer (`malformed accessor binding`);
> - every key in a `[write.<id>]` entry's `keys` list MUST be an **owned** tag (`write to non-owned tag`);
> - every id in a rule's `gate` list MUST resolve to a `[gate.<id>]` entry (`unknown accessor`).
>
> […] This settles the provenance scope §D7(ii) left open at this RDR.

Restated in Risks `0002:2005-2009` ("exactly one reader per owned key, at most one per observed key, none for `recognized`") and Phase 3 `0002:1991-1992` ("the provenance-scoped `keys` bindings").

| Key provenance | Reader arity | Writer arity | Control |

| owned | exactly one | exactly one if written/cleared/`[initial]`-assigned; writer keys must be owned | `neg-owned-no-reader`, `neg-owned-two-readers`, `neg-write-observed`, `probe-a/b-initial-observed-*` |
